Computed syntax rule

How the fallback is selected

Before

input || 5000
Use 5000 if input is falsy.

After

input ?? 5000
Use 5000 only for null or undefined.

If zero reaches this expression, it is now kept. Whether callers supply zero remains a review question.

The ordered review list makes each change expandable, with both revisions and the evidence needed to inspect it.

01

Before and after

Fixed syntax rules describe conditions, defaults, calls, returns and await ordering. Complete unit source stays one expansion away.

02

Reference consumers

Separate before/after projects resolve static callers, imports, renders and type uses. A reference establishes dependency; it does not prove behavioral impact.

03

Visible explanation gaps

Unsupported constructs, excluded files and unresolved imports remain visible. Every changed file has a place, including non-code, binary and metadata changes.

04

Optional reviewer notes

Human or model notes can suggest questions and evidence mappings for supplied criteria. They are marked unverified and bound to the exact analyzed snapshot.
